# Serenity Medical Center — Yaoundé, Cameroon

Multi-page static website prototype based on publicly available information about Serenity Medical Center in Yaoundé.

## Pages
Home, About, Services, General Medicine, Maternal & Child Care, Diagnostics, Surgery & Emergency, Digital Health, Foundation, Community, Community Article, Gallery, Partner, Contact and Admin concept.

## Verified public information used
- Maison Damas / Chris Complex, Yaoundé, Cameroon
- +237 683 539 388
- Open 24 hours
- Established 2020
- Publicly described services include general medicine, maternal and child care, laboratory diagnostics, surgery and emergency services.
- Public branding: Care · Innovation · Quality.

## Important
The site deliberately does not invent private staff names, patient testimonials, financial figures or operational claims. Medical stock imagery is used as design imagery until official Serenity facility/team photographs are supplied.

## Deployment
Upload the project contents to a GitHub repository and enable GitHub Pages from the main branch, root folder.
