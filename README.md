# Serenity Medical Center Website — Cameroon

A polished, responsive front-end concept for Serenity Medical Center.

## Included
- Responsive homepage and navigation
- About Serenity
- Clinical services
- Specialists preview
- Healthcare statistics
- Digital healthcare ecosystem
- Serenity Health Foundation donation interface
- Community/blog preview
- Partner CTA
- Contact form
- Map placeholder
- Mobile navigation
- Scroll reveal animations
- Donation amount interactions
- Accessible semantic HTML

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and open the generated Pages URL.
